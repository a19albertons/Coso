# Coso v1.0.

Juego gratuito con 8 niveles totalmente jugables, distintos objetivos y enemigos. Además, 2 posibles finales derivados de la trama inicial. El final del juego dependera de tu forma de progresar en el juego. 

Actualmente se ofrece soporte para los siguiente sistemas operativos:
- Linux
- Windows
- Web
- MacOS [Experimental]
- Android [Experimental]
- iOS [Experimental]

Se puede jugar en todas las plataformas mencionadas con teclado o mando (las limitaciones que se encuentren depende del soporte de Unity 6.3). En el caso de Android e iOS, se ofrece soporte para pantalla táctil.

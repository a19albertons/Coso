# Coso

## Descripción 

Es un juego plataformas 2D desarrollado en Unity 6.3 que dispone de 8 niveles completamente jugables, algún powerup y varios tipos de enemigos o variantes del mismo. El objetivo del juego el completar todos los niveles que te pone tu novia para poder casarte con ella. El juego dispone de un sistema de vidas, monedas, limite de tiempo por nivel para completarlo y 2 finales posibles dependiendo de la forma que completes el juego.

## Compilación

Existen las versiones compiladas por los workflows (estas caducan con el tiempo) y las releases, pero se puede compilar en local teniendo el unity hub instalado e indicando la url del repositorio. UnityHub debería ser quien de autodetectar la versión y las dependencias automáticamente.
Una vez abierto el proyecto en Unity, se puede compilar para la plataforma deseada desde el menú de File -> Build Profiles o Build And Run.

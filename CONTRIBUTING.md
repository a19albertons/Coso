## Política de uso de la IA

El uso de agentes de inteligencia artificial o chatbots para generar código, documentación o cualquier otro contenido relacionado con el proyecto está permitido, siempre y cuando el que lo propone lo entienda y pueda mantenerlo.

Debe quedar indicado en la descripción de la pull request el software/s usado/s (opencode, claude code...) y el modelo/s de IA (qwen 3.8 27b , oput 5.5...)

# Tests

- Actualmente no hay cobertura mínima de tests para cada función actual o futura que se añada.

# Pull requests

- Actualmente no hay una plantilla de pull request creada, pero se recomienda indicar el motivo del cambio y que arregla, mejora o añade.

# Issues

Estan pensadas para indicar bugs que se descubran, sugerir mejoras, nuevas funcionalidas, indicar degradamiento de rendimiento...
